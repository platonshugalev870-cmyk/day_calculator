# day_calculator
A simple GUI day calculator built with Python and Tkinter.
Features
Date difference — calculate the number of days between two dates
Add days — find the date N days after a given date
Weekday lookup — get the day of the week for any date
Leap year check — determine whether a year is a leap year
Requirements
Python 3.7+
Tkinter (included in standard Python distribution)
Usage
bash
python main.py
Enter dates in DD.MM.YYYY format.

Project Structure
day_calculator/
├── main.py        # Entry point
├── calculator.py  # Calculation logic
├── ui.py          # Tkinter interface
└── utils.py       # Date helpers
